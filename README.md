# Horas Médicas

Aplicación Flutter para acceder rápidamente a las páginas web de clínicas médicas en Rancagua y reservar horas médicas.

## Características

- Acceso directo a 8 clínicas médicas en Rancagua
- Navegación rápida a sitios web de reserva de horas
- Interfaz Material 3 moderna
- Pantallas de Configuración y Acerca de
- Política de privacidad integrada

## Clínicas incluidas

MEDS.CL, FUSAT, ISAMEDICA, INTEGRAMEDICA, INTERSALUD, TORREMEDICA, REDSALUD, CLEVERSALUD

## Requisitos

- Flutter SDK 3.10+
- Dart 3.10+

## Instalación

```bash
git clone https://github.com/operonte/horasmedicas.git
cd horasmedicas
flutter pub get
flutter run
```

## Compilar APK

```bash
flutter build apk --release
```

El APK se genera en `build/app/outputs/flutter-apk/app-release.apk`
